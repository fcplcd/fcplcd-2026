# FCPLCD -- WS 2026/27

Welcome to the GitLab repository for the lecture Foundations of Certified Programming Languages and Compiler Design in the winter semester 2026/27.

This repository only contains the lecture material, such as PDF exports of the lecture slides and the code for the assignments.
For all other information — including the descriptions of the exercises and what you are expected to do — please refer to the course website:

**<https://pages.barkhauseninstitut.org/versa/teaching/fcplcd/26-27/>**

The material in this repository will be updated as the semester progresses.

## Repository contents

- [Lecture slides](lectures/slides/) — PDF exports of the lecture slides
- [Lecture code](lectures/code/) — executable code examples presented during the lecture
- [Exercises](exercises/) — all assignments published so far
